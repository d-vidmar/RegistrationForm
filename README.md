<h1 align="center"> Replica of Stripe login and registration form</h1>


This project is the replica of Stripe login and registration form, **created for educational purposes**. The purpose of this project is to practice HTML and CSS.


## Technologies used
- HTML5
- CSS

## Features
- **Log in page:** has input fields for email and password, both fields are required. When fields are focused, they smoothly change the outline color. Form also includes other sign in buttons: Google, Passkey and SSO. These buttons change border color when hovered, but doesn't do anything when pressed.
- **Registration page:** includes input fields for email, full name and password and option for selecting country. Default selected country is Slovenia.
